# P9: Agent-Native Memory API — Implementation Plan

> **REQUIRED SUB-SKILL:** superpowers:subagent-driven-development
>
> **Prerequisites:** P4-P8 merged or stacked. Branches off `feat/p8-forgetting-decay`.

**Goal:** Expose 5 agent-shaped HTTP endpoints — `/v1/memory/observe`, `/v1/memory/recall`, `/v1/memory/reflect`, `/v1/memory/timeline`, `/v1/memory/forget` — under the existing `/v1` HTTP router. Token-budget aware, streaming-capable, federation-aware, with the existing RSA-JWT auth + K2K allowlist. Map each endpoint to Lin et al.'s 6-phase memory lifecycle (Write, Store, Retrieve, Execute, Share, Forget) so the governance coverage matrix is complete.

**Architecture in one paragraph.** A new module `src/api/memory.rs` defines 5 handler functions plus their request/response DTOs. Routes are registered alongside existing `/v1` endpoints in the K2K server. Each handler is thin: parses the request, dispatches into existing P3-P8 infrastructure (ArticleService for observe, LocalRouter for recall, Reflector for reflect, list_events_for_store for timeline, set_article_tier(Archive) for forget). Token-budget enforcement happens in a new `bundler.rs`: rank results, drop or truncate to fit the requested budget. SSE streaming is opt-in via Accept header. Federation reuses the existing K2K remote-executor path with a new `federate=true` flag.

**Tech Stack:** Existing — axum, tower, tokio, serde, the rest of the stack. No new dependencies.

## Bibliography

### Task 2: Token-budget bundler

**Files:** `src/api/bundler.rs`

- [ ] `fn pack_to_budget(results: Vec<K2KResult>, budget_tokens: u32) -> BundledResponse` that:
  - Estimates tokens per result (rough heuristic: `(title + summary + content).chars().count() / 4` — words-as-tokens).
  - Adds results in rank order until adding the next would exceed budget.
  - Returns `BundledResponse { items, total_budget_used, items_dropped, items_truncated }`.
  - Supports truncation: if even item[0] exceeds budget, truncate its summary/content to fit.
